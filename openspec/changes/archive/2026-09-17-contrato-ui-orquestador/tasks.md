- [x] 1.1 **RED** — Write `tests/test_session.py` (failing before any production code; `uv run pytest tests/test_session.py -q` must fail with import/attribute errors). Cover, with AAA blocks and a fresh `Game(rounds=1, round_timeout=None)` per test (pattern: `tests/test_api_boundary.py` (read-only)):
  - create issues one token + `alias == "Jugador 1"` + 5-char uppercase alphanumeric `room_code`; join issues a distinct token + `"Jugador 2"` (spec: "Create and join issue identity").
  - 1:1 binding: `alias_for(room, token)` returns the exact alias and there is no store API to reassign/forge an alias for a token (spec: "Session store binding" — spoofing impossible by construction).
  - unknown token resolves to `None`; a valid token of *another* room resolves to `None` for this room (catalog semantics: `session_expired` vs `not_a_player`, design Decision 7).
  - room lookup is case-insensitive (lowercase input finds the uppercased code) while the issued code stays uppercase.
  - room-code collision retry: monkeypatch `secrets.choice` to repeat a value once, assert a retry happens and two rooms never share a code.
  - `is_host(room, token)` is True only for the creator's token.

## Phase 2: Core Implementation — HTTP Transport, Routing, Error Mapping (PR 2)

- [x] 2.1 **RED (part A: routing, identity, host)** — Write the first half of `tests/test_server.py` (failing; loopback harness first: a `serve()` contextmanager mirroring `tests/test_engine_integration.py` (read-only) that boots `ThreadingHTTPServer` on port 0 with injected `SessionStore`, fake engine stub, and `game_factory`/`clock`, plus a stdlib `http.client` client helper). Cover:
  - routing table: `POST /rooms` → 201 with `{room_code, session_token, alias}`; `POST /rooms/{code}/join` → 201 distinct token; unknown path → 404 `not_found`; wrong verb on known path → 405 `method_not_allowed`; malformed JSON where a body is required → 400 `malformed_request` (spec: "Unknown path and method", "Transport failures map to codes").
  - mutation statuses: `start`/`messages`/`voting/open`/`votes` → 204; every response carries `Content-Type: application/json` except 204 (spec: "JSON contract responses").
  - **precedence 404→401→403** (design Decision 7): unknown room → `room_not_found` (404); known room + absent/unknown token → `session_expired` (401); known room + valid foreign token → `not_a_player` (403) (spec: "Session store binding").
  - **alias spoofing (key RED, spec: "Alias spoofing impossible")**: message/vote request with a forged `alias` field under a valid token is attributed to the token's own alias; a forged `expected_round` is ignored (server binds round from current state).
  - **host enforcement (key RED, spec: "Non-host start refused")**: non-host `start` and `voting/open` → 403 `forbidden_host_action` AND the domain op is never invoked (assert room still LOBBY afterwards).
  - join after LOBBY → 409 `wrong_state`; unknown token on an authenticated endpoint → 401 (spec: "Join after LOBBY is refused", "Unknown token rejected").
